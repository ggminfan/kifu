# Internationalization / 国际化

Kifu supports `en` and `zh-CN`. `system` uses the primary system language: Chinese with the Hans script (including zh-CN and zh-SG) selects Simplified Chinese; all other languages, including Traditional Chinese, select English. A bare `zh` follows its Unicode locale expansion to Hans.

- **Browser:** starts from `navigator.languages[0]` / `navigator.language`. An explicit choice is stored under `kifu.language` in localStorage; other same-origin tabs receive storage events.
- **Desktop:** reads macOS `AppleLanguages` rather than assuming Finder inherits `LANG`. The choice is stored in the desktop connection store’s `ui.language`. Settings, native menus and existing workspace views update without restarting a service or reloading a page.
- **Embedded views:** receive a validated locale through their host-controlled preload and language event. They remain sandboxed and do not gain access to desktop RPC. Standalone browser preferences are independent of the desktop setting.

The Chinese source text is the message key in `src/shared/i18n/en.json`. Use `tr('文案')` for literals and tagged templates such as ``tr`已连接 ${host}``` for interpolation. Values are inserted unchanged; do not concatenate translated fragments when a full sentence can express the message.

Static UI label maps use `localized(...)` so they are translated when read, not frozen at module initialization. React components subscribe with `useLocale()`. Add the current locale to memoization dependencies when a cached value includes localized labels.

`systemText` is restricted to Kifu-generated diagnostics that may arrive from a server as formatted Chinese messages. Never apply it to session transcripts, user prompts, tool output, code, host aliases, or user-authored skill content. Generated model responses retain their original language.

```bash
pnpm i18n:check
pnpm exec vitest run test/i18n.test.ts
```

The checker catches missing catalog entries and unlocalized JSX text / attributes. Tests verify detection, explicit overrides, parameter preservation, subscriptions, dynamic labels and diagnostic translation. A new message should have both an English translation and UI review at narrow widths.

README.md is the English project landing page; README.zh-CN.md is its Chinese counterpart. Keep feature claims, installation commands and limitations aligned. The longer Chinese technical reference lives in guide.zh-CN.md.
